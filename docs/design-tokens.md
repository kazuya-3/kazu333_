# デザイントークン

実体は `src/styles/tokens.css`。ここはその意図と使い分けの説明です。
色・角丸・影・余白を変えたいときは **tokens.css だけ** を編集してください。

## 1. 色

### ベース（背景）

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--c-base` | `#FBFAF8` | ページ全体の背景。温かみのあるオフホワイト |
| `--c-surface` | `#FFFFFF` | カード・パネルの面 |
| `--c-surface-soft` | `#F4F6FA` | 一段沈めたブロック、区切り帯 |
| `--c-line` | `#E6E8EF` | 細い境界線 |

### メイン

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--c-blue` | `#5AA9E6` | 主役。アイスブルー |
| `--c-blue-deep` | `#2F7DE1` | ボタン・リンクなど操作要素 |
| `--c-lavender` | `#A9A0F0` | 資料・ドキュメント系のカテゴリ色 |
| `--c-mint` | `#6FD6C4` | 完了・安心・システム系の補助色 |

### アクセント

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--c-coral` | `#FF8A80` | クリエイティブ系カテゴリ、注目バッジ |
| `--c-citrus` | `#FFD166` | 少量のみ。セール・新着 |

色数を増やさないため、カテゴリ色は
**システム = ブルー / 資料 = ラベンダー / クリエイティブ = コーラル** の 3 つに固定しています。

### 文字

| 変数 | 値 | コントラスト（`--c-base` 上） |
| --- | --- | --- |
| `--c-text` | `#1D2430` | 15.2:1 |
| `--c-text-sub` | `#5A6478` | 6.4:1 |
| `--c-text-mute` | `#7C8698` | 4.5:1（補助テキストの下限） |

`--c-text-mute` より薄い文字は本文に使いません。

### グラデーション

| 変数 | 内容 |
| --- | --- |
| `--g-hero` | オフホワイト → 淡いアイスブルーのメッシュ |
| `--g-accent` | アイスブルー → ラベンダー（見出しの装飾線・強調ボタン） |
| `--g-mint` | ミント → 透明なブルー |
| `--g-warm` | ラベンダー → 淡いコーラル |

いずれも彩度を抑え、3 色以上を虹状に並べない。

## 2. タイポグラフィ

システムフォント優先（Web フォント読み込み 0、表示が速い）。

```
--font-sans: "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP",
             "BIZ UDPGothic", Meiryo, system-ui, sans-serif;
--font-en:   "Inter", "Helvetica Neue", Arial, sans-serif;  /* ラベル・数字 */
```

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--fs-display` | `clamp(2rem, 6vw, 3.75rem)` | ファーストビュー見出し |
| `--fs-h2` | `clamp(1.5rem, 3.6vw, 2.25rem)` | セクション見出し |
| `--fs-h3` | `clamp(1.125rem, 2.2vw, 1.375rem)` | カード見出し |
| `--fs-body` | `1rem`（モバイル `1.0625rem`） | 本文。16px を下回らない |
| `--fs-sm` | `0.875rem` | 補助 |
| `--fs-label` | `0.75rem` | 英字ラベル（`letter-spacing: .12em`） |

行間は本文 `1.9`、見出し `1.35`。日本語の可読性を優先して広めに取ります。

## 3. 余白

8px グリッド。`--sp-1: 4px` 〜 `--sp-16: 128px`。
セクション間は `--section-gap: clamp(4.5rem, 10vw, 8rem)`。
「大胆な余白」はこの変数を大きくするだけで全体に効きます。

## 4. 角丸

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--r-sm` | `10px` | チップ・タグ |
| `--r-md` | `16px` | 入力欄・小さいカード |
| `--r-lg` | `24px` | 標準カード |
| `--r-xl` | `32px` | 大きいパネル・画像 |
| `--r-pill` | `999px` | ボタン・バッジ |

## 5. 影

すべて黒ではなく **青みを含む影**（`rgba(31, 58, 105, …)`）。淡く広く落とします。

| 変数 | 用途 |
| --- | --- |
| `--sh-sm` | 常時のカード |
| `--sh-md` | ホバー時 |
| `--sh-lg` | 浮遊要素・モバイル固定バー |
| `--sh-glow` | アクセントボタンの発光 |

## 6. モーション

| 変数 | 値 |
| --- | --- |
| `--ease` | `cubic-bezier(.22,.61,.36,1)` |
| `--ease-out-back` | `cubic-bezier(.34,1.4,.64,1)`（押下感・カード出現） |
| `--dur-fast` | `140ms` |
| `--dur` | `260ms` |
| `--dur-slow` | `520ms` |

`prefers-reduced-motion: reduce` のとき、`global.css` の一括指定で
アニメーション時間を `0.01ms` にし、浮遊・視差・出現を無効化します。

## 7. レイアウト

| 変数 | 値 |
| --- | --- |
| `--w-page` | `1120px` |
| `--w-narrow` | `760px`（記事・法的ページ） |
| `--pad-x` | `clamp(1.125rem, 5vw, 2.5rem)` |
| `--header-h` | `64px` |
| `--bottombar-h` | `62px`（モバイル固定 CTA。`env(safe-area-inset-bottom)` を加算） |

## 8. ブレークポイント

| 名称 | 幅 | 確認端末の想定 |
| --- | --- | --- |
| xs | 〜359px | 小型スマートフォン |
| sm | 360–429px | iPhone SE / Android 標準 |
| md | 430–767px | 大型スマートフォン・横向き |
| lg | 768–1023px | タブレット |
| xl | 1024px〜 | デスクトップ |

CSS はモバイルを既定値として書き、`min-width` で拡張します。
横スクロールを出さないため、全ページで `overflow-x: hidden` ではなく
グリッドの `minmax(0, 1fr)` と `max-width: 100%` で対処しています。
