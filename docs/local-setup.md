# パソコンで開いて編集する

Cursor（または VS Code）でこのサイトを開き、手元で触りながら編集するための手順です。
はじめての方向けに、順番どおりに進めれば終わるように書いています。

所要時間は 15 分ほど（うち待ち時間が半分くらい）です。

---

## 1. 必要なものを入れる（最初の1回だけ）

3 つだけです。すでに入っていれば飛ばしてください。

### Git

ファイルの変更履歴を扱う道具です。GitHub とのやりとりに使います。

- **Windows**: <https://git-scm.com/download/win> → ダウンロードして「次へ」で進めれば大丈夫です
- **Mac**: ターミナルで `git --version` と打つと、入っていなければインストールを案内されます

### Node.js

サイトを組み立てるための実行環境です。**LTS（推奨版）** を選んでください。

- <https://nodejs.org/ja> からダウンロード
- 必要なバージョンは 18.20 以上（LTS を入れれば問題ありません）

### Cursor

エディタです。<https://cursor.com> からダウンロードしてインストールします。

> VS Code をお使いなら、そのままでも構いません。以降の手順は同じです。

### 入ったか確認する

Cursor を開き、メニューの **ターミナル → 新しいターミナル** を選んで、次を打ちます。

```bash
git --version
node --version
```

それぞれバージョン番号が出れば準備完了です。
出ない場合は、Cursor を一度閉じて開き直すと認識されることがあります。

---

## 2. サイトを手元にコピーする

作業用のフォルダを決めて（例: `書類` の中）、そこでターミナルを開き、次を実行します。

```bash
git clone https://github.com/kazuya-3/kazu333_.git
cd kazu333_
```

初回は GitHub のログインを求められることがあります。画面の案内に従ってください。

Cursor で開くには、**ファイル → フォルダーを開く** から `kazu333_` を選びます。

> 拡張機能のインストールを勧める通知が右下に出たら、**「インストール」** を押してください。
> `.astro` ファイルの色分けやエラー表示が効くようになります。

---

## 3. 準備コマンドを1回だけ実行する

Cursor のターミナルで：

```bash
npm install
```

数分かかります。「added ○○ packages」と出れば完了です。

---

## 4. サイトを表示してみる

```bash
npm run dev
```

ターミナルに URL が出るので、ブラウザで開きます。

```
http://localhost:4321/kazu333_/
```

**ファイルを保存すると、ブラウザが自動で更新されます。**
試しに `src/data/site.json` の `tagline` を書き換えて保存してみてください。すぐ反映されます。

止めるときは、ターミナルで `Ctrl + C`（Mac も `Ctrl`）を押します。

---

## 5. 編集する — 2 つのやり方

### A. 管理画面で編集する（文章・画像・商品）

コードを触らずに、フォームで編集できます。

```bash
npm run cms
```

ブラウザで <http://localhost:4321/kazu333_/admin/> を開き、
**「Work with Local Repository」** を押して、`kazu333_` フォルダを選びます。

- 実績・商品の追加、削除、並べ替え
- 画像のドラッグ＆ドロップ
- トップの見出しや FAQ などの文言

が画面から編集できます。保存すると、手元のファイルが書き換わります。

> Chrome か Edge、または Cursor 内蔵ブラウザではなく通常のブラウザで開いてください。
> Safari は「Work with Local Repository」に対応していません。

### B. コードを直接編集する（見た目・レイアウト）

Cursor でファイルを開いて書き換えます。よく触る場所は次のとおりです。

| 変えたいもの | ファイル |
| --- | --- |
| 色・余白・影・角丸 | `src/styles/tokens.css` |
| トップページの構成 | `src/pages/index.astro` |
| 各セクションの見た目 | `src/components/home/` |
| 料金・見積もりのルール | `src/config/pricing.ts` |
| 文章・実績・商品 | `src/data/` |

Cursor の AI に聞くときは、そのまま日本語で「トップの背景をもう少し明るくして」のように
頼めば大丈夫です。プロジェクトの決まりごとは `CLAUDE.md` と `.cursor/rules/` に
書いてあるので、AI もそれを踏まえて答えます。

---

## 6. 変更を公開する

手元で直しただけでは、公開サイトは変わりません。次の 3 つで反映されます。

```bash
git add -A
git commit -m "トップの文言を修正"
git push origin main
```

push すると自動でビルドが走り、**2〜3 分で** <https://kazuya-3.github.io/kazu333_/> に反映されます。

進み具合は <https://github.com/kazuya-3/kazu333_/actions> で見られます。
緑のチェックが付けば完了です。

### 公開前の確認（おすすめ）

```bash
npm run build
```

これが通らないと公開もされません。push の前に一度実行しておくと安心です。

---

## 7. 困ったときは

| 症状 | 対処 |
| --- | --- |
| `npm` が見つからない | Node.js を入れ直し、Cursor を再起動 |
| `npm run dev` でエラー | `npm install` をもう一度実行 |
| ブラウザが真っ白 | URL の末尾 `/kazu333_/` が抜けていないか確認 |
| 管理画面が開かない | `npm run cms` で起動しているか、Chrome / Edge を使っているか確認 |
| 画像が出ない | `src/assets/` に置いたか、JSON のパスが `/src/assets/...` になっているか確認 |
| push できない | `git pull origin main` してから、もう一度 push |
| 変更を取り消したい | `git checkout -- .`（保存前の状態に戻ります） |

### 元に戻したい

公開してしまった変更を取り消すときは、GitHub の
<https://github.com/kazuya-3/kazu333_/commits/main> から該当のコミットを開き、
**Revert** を押します。取り消しのコミットが作られ、自動で再公開されます。

---

## 覚えておくコマンドは 4 つ

```bash
npm run dev     # 見ながら編集する
npm run cms     # 管理画面つきで起動する
npm run build   # 公開前の確認
git add -A && git commit -m "説明" && git push origin main   # 公開する
```

これだけで日常の更新はまわります。
