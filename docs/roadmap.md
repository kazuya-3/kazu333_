# 今後の拡張候補

MVP には含めていないものの、いまの構成のまま無理なく足せることを優先度順にまとめています。
「MVP で作り込まない」と決めたもの（ログイン・会員登録・独自カート・在庫管理・レビュー・
クーポン・独自決済基盤・管理画面・CMS・複雑な通知）は、いずれもこの表の外側にあります。

## 優先度: 高（公開直後に効く）

| 項目 | 内容 | 想定の作業 |
| --- | --- | --- |
| 問い合わせの本番接続 | `mock` → Formspree もしくは自前 API へ | `.env` の設定と送信テストのみ |
| 実績・商品の差し替え | サンプルを実データへ | `src/config/works.ts` / `products.ts` |
| 法的表記の記入 | 「要入力」項目を埋め、内容を専門家へ確認 | `src/config/legal.ts` |
| アクセス解析 | 訪問数・どの導線が使われているかの把握 | `PUBLIC_ANALYTICS_ID` を読むスクリプトを `BaseLayout` に追加 |
| 見積もり利用の計測 | どのステップで離脱しているか | ウィザードのステップ遷移でイベント送信 |

## 優先度: 中（運用が楽になる）

| 項目 | 内容 | 想定の作業 |
| --- | --- | --- |
| スパム対策の強化 | Cloudflare Turnstile / reCAPTCHA | 送信アダプター内でトークンを付与。UI 変更は不要 |
| 自動返信メール | 送信者へ控えを送る | サーバー側（`endpoint` アダプター）で対応 |
| 実績の Markdown 化 | 本文が長くなってきたら Content Collections へ | `src/content/works/*.md` + スキーマ定義。`Work` 型はそのまま流用できる |
| 実績のタグ絞り込み | カテゴリに加えて使用技術でも絞る | 既存のフィルタ実装を拡張 |
| 検索 | 実績・商品・FAQ の横断検索 | 静的な JSON インデックス + クライアント側の絞り込み |
| ページ別 OGP 画像 | 実績・商品ごとに専用の共有画像 | `astro:assets` の動的生成、または `scripts/generate-og.mjs` の拡張 |
| ブログ / 制作メモ | 検索流入と信頼づくり | Content Collections で追加。ナビとフッターに 1 項目足すだけ |

## 優先度: 低（必要になったら）

| 項目 | 内容 | 前提 |
| --- | --- | --- |
| 購入者向けダウンロード | 決済後に限定ファイルを配布 | 決済事業者の Webhook を受けるサーバーが必要。URL パラメータだけで購入を信用しないこと |
| 購入 Webhook | 売上の記録・在庫の反映 | 同上。署名検証は必須 |
| 多言語対応 | 英語ページ | Astro の i18n ルーティング。`src/config/` を言語別に分ける |
| ダークモード | 配色の切り替え | `tokens.css` に `prefers-color-scheme` の変数セットを追加。トークン化済みのため CSS 変更のみで済む |
| 予約・空き状況表示 | 受付可否をサイトに出す | 手動更新なら `src/config/site.ts` にフラグを 1 つ足すだけで始められる |
| 実績の動画・GIF | カード内で短いデモを見せる | `<video muted playsinline>` + `prefers-reduced-motion` で静止画へ切り替え |

## 設計上、すでに拡張を見込んである箇所

- **問い合わせ送信**: `src/lib/contact/` のアダプター構造。
  `ContactAdapter` を満たすファイルを足して `index.ts` の `switch` に 1 行加えるだけで切り替わる。
- **決済**: 商品データの `purchaseUrl` は外部リンク前提。
  将来サーバーを持つ場合も、商品データの形は変えずに済む。
- **見積もりロジック**: 料率は `src/config/pricing.ts` に集約、計算は `src/lib/estimate.ts` の純関数 1 つ。
  選択肢を増やしても画面側の変更は不要。
- **デザイン**: 色・余白・角丸・影・モーションはすべて `src/styles/tokens.css` の CSS 変数。
  配色変更はこのファイルだけで完結する。
- **URL 構造**: 内部リンクは `src/lib/url.ts` の `url()` 経由。
  サブディレクトリ公開から独自ドメインへの移行が環境変数 2 つで済む。

## 意図的に採用しなかったもの

| 見送ったもの | 理由 |
| --- | --- |
| CSS フレームワーク（Tailwind 等） | ページ数が少なく、トークン + スコープ付き CSS で足りるため。依存とビルド時間を増やさない |
| アニメーションライブラリ（GSAP / Framer Motion） | 必要な演出は CSS と IntersectionObserver 約 60 行で実現できたため |
| React | Preact で API はほぼ同じまま、島 1 つあたり約 40KB 軽くなるため |
| Web フォント | 日本語フォントは容量が大きく、初回表示を確実に遅くするため。システムフォントで統一 |
| 独自カート・会員機能 | MVP の範囲外。外部販売サービスで十分成立するため |
